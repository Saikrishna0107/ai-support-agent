# Returns and Refunds

## Return window

Most items can be returned within 30 days of the delivery date. Items bought between November 1 and December 24 have a longer holiday return window. See the Holiday Returns page.

## Condition requirements

Returned items must include all original accessories, cables, manuals, and packaging. If accessories are missing, their replacement cost is deducted from your refund.

## Items with special return rules

| Item type | Rule |
|---|---|
| Opened TVs and drones (not defective) | 15% restocking fee |
| Drones that have been flown | Returnable only if defective |
| Opened in-ear audio products, such as Pulse Buds Pro | Returnable only if defective, for hygiene reasons |
| Gift cards | Not returnable |
| Digital download codes | Not returnable once the code has been revealed |
| Kestrel Care protection plans | Cancel the plan instead of returning it. See the Kestrel Care page. |

Unopened items in their original sealed packaging never have a restocking fee. Defective items never have a restocking fee.

## How to start a return

1. Go to Orders in your account and select "Start a return" next to the item. Guest shoppers can use the Order Lookup page with their order number and email address.
2. Choose a reason. If the item is defective, describe the problem.
3. Print the prepaid return label we email you and drop off the package at any carrier location within 14 days.

## Return shipping cost

- Defective items and items we sent by mistake: free return shipping.
- All other returns: $6.99 is deducted from your refund for the return label.
- Kestrel Rewards Gold members get free return labels on all returns.

## Refunds

- We inspect returned items within 3 business days of receiving them.
- After inspection, refunds go to the original payment method. Banks usually take 5–7 business days to show the refund.
- Orders paid with a gift card are refunded to a new Kestrel gift card.
- Original shipping charges are refunded only if the item was defective or we sent the wrong item.
- Pay in 4 orders are refunded to the installment plan, and any remaining payments are reduced or canceled.

## Exchanges

To exchange an item for the same product in a different color or size, choose "Exchange" when you start a return. Exchanges for the same product have no restocking fee and free shipping both ways. To exchange for a different product, return the original item and place a new order.
